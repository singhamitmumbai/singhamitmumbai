# Runtime entrypoints

- `python -m cognitive_ai` — default Mother AI REPL (NL + symbolic)
- `python -m cognitive_ai mother` — Mother AI interactive
- `python -m cognitive_ai diagnose` — Mother diagnostics
- `python -m cognitive_ai benchmark` — FinderBench
- `python -m cognitive_ai status` — Mother status JSON
- `python -m cognitive_ai complete-ai` — CompleteAI product
- `python -m cognitive_ai assistant` — Finderbay Assistant
- `python -m cognitive_ai chat` — Chat UI
- `python -m cognitive_ai learn` — 24/7 continuous learning
- `python -m cognitive_ai repl` — classic symbolic REPL (NL fallback on)
